# staging/

Candidate pools: raw material waiting to be curated. **Nothing here is part of the dataset.** The validator and build ignore this folder.

An item moves from a pool into `data/` only when someone promotes it in a batch: they give it threads and regions, write a neutral summary, attach sources, and link it to other items.

## Pools

| File | Produced by | One row is |
|---|---|---|
| `wikidata-events.csv` | `tools/importers/wikidata_events.py` | one Wikidata event from 1900 onwards |

Pools are regenerated by their importer. Do not edit them by hand.
